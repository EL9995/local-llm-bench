How it ends

⚖

Debaters, in speaking order

      Temperature

      0 gives the same answer every time; higher lets answers vary more. Default is the temperature the model ships with, marked with a tick on its slider.

      Vision

      Each model that can see images reads the photo on its own. The final agent combines what they found, then does what you typed, if anything.

      With several photos

      Debate

      Round 0: everyone answers alone. Then each discussion round, every model reads the whole conversation so far and replies.
